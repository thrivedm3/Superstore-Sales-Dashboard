# 📊 Superstore Sales Dashboard

## 1. 📝 Short Description
A single-page Power BI dashboard analyzing retail sales performance for a national superstore chain, covering revenue, profitability, and fulfillment across product categories, regions, and customer segments. Built as a hands-on practice project to strengthen data modeling, DAX, and dashboard design skills.

## 2. 🛠️ Tech Stack
- **Power BI Desktop** - data modeling and report design
- **Power Query (M)** - data cleaning and shaping
- **DAX** - calculated measures

## 3. ✨Highlights

### 🧩 Business Problem
Sales and profit data was scattered across raw transactional records, with no easy way to see which products, regions, or segments were performing well or where profitability was slipping in different levels.

### 🎯 Goal of the Dashboard
Consolidate order level data into a single interactive view that lets monitor overall sales and profit health, compare performance across categories, ship modes, and regions, and track trends over time.

### 📌 KPI Walkthrough
- 💵 **Total Sales** - Aggregate revenue across all orders
- 📈 **Total Profit** - Aggregate profit after cost.
- ⏱️ **Average Delivery Time** - Average days from order to fulfillment.

### 💡 Business Insights
- 🏆 Pinpoints which categories and sub-categories carry the most revenue versus which underperform.
- ⚖️ Separates high-revenue categories from high-profit categories.
- 🚩 Flags regions or ship modes with longer delivery times, pointing to where fulfillment operations may need attention.
